# 동아사이언스 경량 모니터링

동아사이언스 공개 서비스 3곳의 메인 페이지 상태를 30분마다 점검합니다.
로그인·결제 등 계정 관련 점검은 하지 않으며, 공개 페이지 접속 확인만 수행합니다.

| 서비스 | 점검 URL |
|---|---|
| DS스토어 | https://dsstore.dongascience.com/main |
| 동아사이언스 닷컴 | https://www.dongascience.com/ko |
| d라이브러리 | https://dl.dongascience.com |

## 동작 방식

- **주 발사 = Google Apps Script** (2026-07-11부터): 30분마다 GitHub API `workflow_dispatch`로 점검을 발사합니다. GitHub 크론이 예약 실행을 대량 누락하는 문제(실측: 시간당 6회 발사 중 90% 이상 유실)를 우회하기 위한 구조입니다.
- **백업 = GitHub 크론**: 시간당 6회(:07 :17 :27 :37 :47 :57) 크론을 백업으로 유지하며, 사전 체크의 dedup 가드(최근 25분 내 이력 존재 시 스킵)가 어느 경로로 발사되든 실제 점검을 30분당 1회로 제한합니다.
- 요일·공휴일 구분 없이 24시간, 30분 간격으로 점검합니다 (일 48회).
- 점검 항목: 페이지 로드 + 콘텐츠 링크 노출 + 이미지 로딩 + 응답 속도 (Playwright)
- 이상·느림·이미지 깨짐 감지 시에만 잔디(Jandi) 알림을 발송합니다.
- **교차 재점검 (2026-08-01~)**: 이상 감지 시 곧바로 알리지 않고 별도 러너에서 같은 점검을 1회 반복합니다. 이상이 재현될 때만 알림을 발송하고, 재현되지 않으면 러너 경로 문제(오탐)로 확정해 이력에 `runnerIssue`로 기록합니다 (특정 러너에서 대상 도메인만 막히는 오탐 실사고 대응 — 알림은 이상 시 3~8분가량 늦어지는 대신 오탐이 걸러집니다). 재점검 잡 자체가 실행되지 못하면 ⚠️ 미확정 통보를 보냅니다.
  - 알려진 한계 (수용): 재점검 도달 전에 자연 복구된 진짜 단기 장애(수 분 규모)는 러너 오탐과 구분할 수 없어 알림 없이 `runnerIssue`로 기록됩니다. "지금은 정상"이므로 알림 생략이 의도된 동작입니다.
- **러너 자체 고장(카나리 실패) 시에도 즉시 재점검 (2026-08-02~)**: 점검 러너의 인터넷이 통째로 불능이면 그 관측은 무효 처리하고(`runnerIssue`), 30분을 기다리지 않고 곧바로 별도 러너에 재점검을 넘깁니다. 재점검 러너에서 ① 정상이면 무음 ② 서비스 이상이 확인되면 🚨(단독 판정 표기) ③ 재점검 러너마저 네트워크 불능이면 ⚠️ "판정 불가 — 확인 필요"를 발송합니다. 알림 발송은 모두 3회 재시도.
- **알림 음소거 (2026-11-04~)**: 이미 아는 장애를 내부에서 조치하는 동안, `docs/data/mute.json`으로 **그 서비스만** 알림과 교차 재점검을 멈출 수 있습니다. 점검·판정·이력은 그대로라 대시보드 가동률과 복구 시점은 나중에 그대로 확인되고, 음소거하지 않은 서비스가 하나라도 이상이면 알림은 평소대로 나갑니다. 러너 네트워크 문제(⚠️ 판정 불가)는 감시 체계 자체의 경고라 음소거 대상이 아닙니다.

  ```json
  { "dotcom": { "until": "2026-11-04T09:00:00+09:00", "reason": "접속 장애 — 내부 조치 중" } }
  ```

  서비스 키는 `dsstore` · `dotcom` · `dl`. **만료 시각(`until`)은 필수**이고, 없거나 형식이 틀리거나 만료가 24시간보다 멀면 무시하고 알립니다 — 끄고 잊는 것이 이 기능의 유일한 실패 모드라 막아둔 장치입니다. 만료되면 파일을 손대지 않아도 알림이 되살아납니다. 이 저장소는 공개이므로 `reason`에 서버·계정·담당자 같은 내부 상세를 쓰지 않습니다.
- 결과는 `docs/data/history-light.json`에 최근 24시간 보관되며, 별도 대시보드가 이 파일을 조회합니다.

|---|---|
| `JANDI_WEBHOOK_URL` | 잔디 Incoming Webhook URL (미설정 시 알림 없이 이력만 기록) |

## 수동 실행

Actions 탭 → 경량 모니터링 → **Run workflow** (force 체크 시 dedup 무시)

수동 실행도 교차 재점검이 그대로 적용됩니다 — 이상이 있어도 알림은 재점검 잡이 끝난 뒤(수 분 후)에 옵니다.
